# 🎮 炒股大作战 · 你 vs 量化（mockstock）

模拟炒股游戏：你和一个量化策略各拿 $100,000，从同一个 Day 0 开始对战。

- **🎯 选股大厅**（首页）：全市场约 530 只美股，关卡式筛选（今日买点 / 强势榜 / 做空雷达 / 超跌反弹 / 放量异动），
  点任意一只 → 技术图表 + 直接 **买入 / 做空 / 平仓**
- **⚔️ 对战**：记分牌、拔河条、日胜负、收益曲线、成就徽章、战况播报
- **🤖 量化对手**：按历史检验为 A / B 级的 O'Neil 买卖点自动交易（收盘决策、次日开盘成交，最多 10 只等权，8% 止损），打开页面自动补算
- **📜 战报**（可下载）、**🧪 回测实验室**（同一套撮合规则调参）、板块雷达、持仓信号

规则：零佣金、0.05% 滑点；可做空，不加杠杆（多空总市值 ≤ 净值）；只交易美股。
数据保存在 `data/sim_*.json`（交易流水是唯一数据源），配置 `GITHUB_TOKEN` / `GITHUB_REPO` 后自动同步回仓库。

```bash
pip install -r requirements.txt
streamlit run app.py
```

仅供模拟游戏，非投资建议。
