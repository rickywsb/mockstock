# 模拟盘 mockstock

从「小猪小眼基金公司」拆出的动量模块 + 全市场选股器，加上两个模拟账户：

- **自动策略**：按历史检验为 A / B 级的 O'Neil 买卖点信号自动买卖（收盘决策、次日开盘成交，最多 10 只等权，8% 止损）
- **我的账户**：自己下单（最新价 / 收盘价），作为对照

两个账户同一 Day 0、同样 $100,000 初始资金、0.05% 滑点、零佣金。页面打开时自动补算到最近收盘日。
另有持仓报告（可下载）、回测（同一套撮合规则）、市场（选股器 / 板块雷达）、个股信号（量能健康）。

数据保存在 `data/sim_*.json`（交易流水是唯一数据源），配置 `GITHUB_TOKEN` / `GITHUB_REPO` 后自动同步回仓库。

```bash
pip install -r requirements.txt
streamlit run app.py
```

仅供模拟研究，非投资建议。
